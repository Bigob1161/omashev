# Omashev — семейное древо

Сайт семейного древа: 3D-история «от чая к древу» в росписи «Пахта», схема поколений, карточки родственников, русский и узбекский языки.

- **Публичная версия (только просмотр):** https://bigob1161.github.io/omashev/
- **Код сайта и инструкции:** папка [`family-tree`](family-tree/README.md)

Древо ведётся локально (`family-tree/server.py`), а публичная копия обновляется командой:

```bash
cd family-tree && python3 publish_static.py
```

После неё нужно отправить изменения папки `docs/` на GitHub. Всё, что лежит в `docs/`, видно любому, у кого есть ссылка.
