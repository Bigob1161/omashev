# Nasl — семейное древо

Закрытый цифровой архив семьи. Родственники открывают ссылку, один раз вводят общий **семейный код** и вместе пополняют древо: люди, связи, фотографии, документы, воспоминания. Регистрации нет.

## Что внутри

**Главная страница — история «от чая к древу»**
- Первый экран: узбекский чайник и пиала в росписи «Пахта» (кобальт и белые коробочки хлопка), блюдце, пар над крышкой. Модели процедурные (геометрия вращения), роспись рисуется на canvas — без внешних файлов.
- Одна непрерывная анимация, привязанная к прокрутке (GSAP ScrollTrigger + React Three Fiber): чайник приподнимается и наливает чай, пиала наполняется, чай начинает светиться, световые нити поднимаются и сплетаются в ствол, вырастают ветви из тёмного дерева с золотыми прожилками, на них по поколениям появляются медальоны с портретами, затем камера отдаляется и дерево складывается в читаемую схему. При прокрутке назад всё идёт обратно.
- Структура дерева берётся только из родственных связей. Если своих данных нет, показывается вымышленная демонстрационная семья с пометкой «Демонстрационные данные».
- Секции «История начинается с нас», «Поколения, объединённые временем», «Каждое имя хранит историю», «Семейный архив» и финал с чайником и выросшим деревом.

**Моё древо**
- Схема: родители над детьми, супруги рядом, плавные линии родства. Перемещение и масштаб мышью, пальцем и клавиатурой. При выборе человека подсвечивается его ближайшая семья. Есть фильтр по поколениям и поиск по имени.
- Художественное 3D: та же семья на объёмной скульптуре. Её можно вращать и приближать, а нажатие на портрет открывает карточку.

**Карточка человека**: портрет, фамилия при рождении, даты и места рождения и смерти, биография, родители, супруги, дети, братья и сёстры, фотографии, документы (PDF и сканы), воспоминания родных. Здесь же можно редактировать сведения и добавлять родственников. Неизвестные данные подписаны нейтрально: «Дата неизвестна», «Место неизвестно».

**Семейный архив**: вкладки «Материалы» (фото, документы, воспоминания), «Лента поколений» и «Журнал изменений» (любую правку можно отменить). Кнопка «Скачать резервную копию» выгружает всё древо в JSON (`/api/export`, формат `nasl-family/1`: `people`, `relations`, `photos`, `memories`; сами файлы фото лежат в `data/photos`).

**О проекте**: как работает сайт и где на самом деле хранятся данные.

**Защита данных**
- Нельзя сделать человека своим предком, указать троих родителей, поженить близких кровных родственников.
- При добавлении похожего человека (то же имя и год рождения) сайт предупреждает о возможном дубле.
- Удалённое не стирается насовсем, его можно вернуть.

**Языки**: русский и узбекский (современная латиница), переключатель RU | UZ. Выбор запоминается. При переключении страница не перезагружается и положение в древе не сбрасывается. Словари лежат в `web/src/i18n/`. Узбекскую кириллицу можно добавить отдельным файлом той же структуры.

**Доступность и скорость**
- Работает с клавиатуры, учитывает настройку «уменьшить движение».
- На устройствах без WebGL вместо 3D показывается статичное изображение.
- На телефоне меньше частиц и нет теней.
- 3D-часть загружается отдельно, поэтому главная открывается быстро.

## Устройство

```
family-tree/
├── server.py         сервер на Python без зависимостей: API, база SQLite, фото
├── web/              интерфейс: React + TypeScript + Vite + React Three Fiber + GSAP
│   └── src/
│       ├── three/    3D-скульптура: модель древа, сцена, текстуры медальонов
│       ├── pages/    страницы: главная (история и секции), древо, история, архив
│       ├── components/  карточки, панель человека, схема, диалоги, навигация
│       ├── i18n/     словари RU и UZ
│       ├── lib/      раскладка древа, родство, данные
│       └── store/    состояние приложения
├── static/           прежняя простая версия сайта (открывается по адресу /classic/)
└── Dockerfile        сборка интерфейса и запуск сервера одним образом
```

## Запуск на своём компьютере

Нужны Python 3.8+ и Node.js 20+.

```bash
cd web && npm install && npm run build && cd ..
FAMILY_CODE="придумайте-код" python3 server.py
```

Откройте http://localhost:8000.

Для разработки интерфейса запустите сервер, как выше (с `PORT=8765`), а в другом окне выполните `cd web && npm run dev` и откройте http://localhost:5173. Запросы к данным уйдут на Python-сервер.

### Настройки сервера

| Переменная | Что значит | По умолчанию |
|---|---|---|
| `FAMILY_CODE` | Общий код для входа. **Обязательно задайте** | пусто (вход без кода) |
| `PORT` | Порт | `8000` |
| `DATA_DIR` | Где хранить базу и файлы | `data/` рядом с `server.py` |
| `TRUST_PROXY` | `1`, если сайт стоит за прокси (Render, Railway, nginx) | выключено |

## Как выложить в интернет

Нужен хостинг с **постоянным диском** для базы и фотографий:

1. **VPS** (Timeweb Cloud, Selectel, REG.RU, Hetzner), от 200–400 ₽ в месяц. Соберите интерфейс (`npm run build`), скопируйте папку на сервер и запустите `server.py` как службу или через Docker. Для HTTPS поставьте Caddy или nginx и задайте `TRUST_PROXY=1`.
2. **Render / Railway / Fly.io**: загрузите папку в GitHub и создайте сервис из `Dockerfile` (он сам соберёт интерфейс). Подключите диск к `/data`, задайте `FAMILY_CODE` и `TRUST_PROXY=1`.

Обязательно включите HTTPS.

## Доступ для родственников и резервные копии

- Отправьте в семейный чат ссылку и семейный код. Чтобы сменить код, поменяйте `FAMILY_CODE` и перезапустите сервер.
- Все данные лежат в одной папке (`data/` или `DATA_DIR`): `family.db` и `photos/`. Регулярно копируйте её.
